# QuickServe UI screens

All screens and states from the QuickServe UI Design Brief, drawn as static Bootstrap 5 markup with Bootstrap Icons.

- Open `index.html` in a browser to view the board (self-contained, no network needed).
- `src/customer.mjs`, `src/staff.mjs`, `src/owner.mjs` hold the screens; `src/lib.mjs` holds the shared helpers; `src/qs.css` is the brand theme on top of Bootstrap.
- Rebuild after editing: `node design/build.mjs`

QR codes are placeholders, not scannable codes.
